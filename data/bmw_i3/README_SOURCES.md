# MaintiDoc BMW i3 - Corpus V3

Ce dossier contient 35 PDF techniques de 8 pages chacun pour le corpus multimodal MaintiDoc.

- Les informations techniques sont fondées sur les sources BMW/NHTSA indiquées dans chaque document et dans corpus_index.csv.
- Les visuels sont des photographies réelles de BMW i3 ou de composants réels utilisées comme supports de reconnaissance visuelle.
- Les visuels ne constituent pas, à eux seuls, une preuve diagnostique.
- Toute intervention haute tension doit être réalisée par du personnel qualifié conformément aux procédures constructeur.
